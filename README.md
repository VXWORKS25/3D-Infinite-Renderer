# 3D Infinite Renderer

مشروع ويب بسيط يوضح مشهدًا ثلاثي الأبعاد متواصلًا، مع شخصية بأسلوب هيكل عظمي/بدلة حمراء، في مشهد يبدو بلا حدود مع حركة مستمرة.

## التشغيل

1. افتح مجلد المشروع.
2. شغل خادم محلي، مثل:

```bash
python -m http.server 8000
```

3. افتح المتصفح على:

```text
http://localhost:8000
```

## ماذا يحتوي المشروع

- مشهد ثلاثي الأبعاد باستخدام Three.js
- حركة كاميرا مستمرة
- أرضية/طريق يبدو بلا نهاية
- شخصية متحركة قائمة على أشكال هندسية بسيطة
- تصميم أبيض/رمادي أنيق وواجهة HUD بسيطة

## ملاحظات

هذا المشروع مناسب كقاعدة لبناء نموذج ثلاثي الأبعاد أكبر أو تحويله إلى لعبة/واقع افتراضي في المستقبل.

## الصور

يمكنك تعديل الألوان والأشكال في `app.js` لتغيير مظهر الشخصية أو المشهد.
